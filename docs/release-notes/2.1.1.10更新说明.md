# Reader Sync 2.1.1.10 更新说明

本版本在完整保留 2.1.1.9 的基础上，处理两类使用反馈。

## 1. 提升英文台本匹配稳定性

- 在匹配前统一常见英文缩写与口语写法，例如 `I'm / I am`、`don't / do not`、`gonna / going to`。
- 匹配时保留有意义的单字词 `I` 和 `a`。
- 没有降低原有匹配门槛，避免为了提高数字而引入错误跳转。

不同剧集的台本与字幕可能存在删句、合句或文本版本差异，因此匹配率仍可能随剧集变化。播放器对未直接命中的段落仍会使用相邻锚点补齐时间。

## 2. 修复只配置单一版本文件夹的问题

- 选择 `「纯英」老友记 SE01` 这类目录时，顶层文件夹名现在也会参与版本识别。
- 如果目录中实际只有纯英、双语或无字幕中的一种，且旧设置选择了另一种，插件会自动切换到唯一可用的版本。
- 包含多个版本的媒体库仍严格遵循用户选择，不会偷偷切换。

## 安装

在浏览器扩展管理页面打开开发者模式，选择“加载已解压的扩展程序”，然后选择整个 `Reader-Sync-2.1.1.10-浏览器导入目录` 文件夹。
