# Reader Sync Player 2.1.1.3：本地媒体库

本版本是在 `2.1.1.2-mp4v-fix` 的独立副本上增加功能；桌面的旧修复版目录和 ZIP 均未改动。

## 新功能

- 选择一次本地资源总文件夹，递归索引其中的 MP4、MKV。
- 根据 Reader 当前页面自动识别 `SxxExx`，自动载入相应视频，无需每集拖放。
- 支持 `S01E01`、`老友记S01E01`、`SE01.01` 等文件命名。
- 同一集存在多个资源时，可优先选择纯英版、双语版、无字幕版或自动选择。
- 可以在扫描时预先处理每一集的优先版本；输出写入媒体文件夹内的 `ReaderSync-Processed` 子目录，不覆盖源文件。
- 配置和扫描索引存于浏览器本机。视频不会上传。

## 使用方法

1. 在 `chrome://extensions/` 中加载本文件夹；请先关闭其他 Reader Sync 版本，避免重复响应。
2. 打开 Reader 剧集页面，并进入扩展播放器的“视频文件”步骤。
3. 在“本地媒体库”区域选择同集多版本的优先级。
4. 如希望提前批量转换不兼容视频，勾选“配置时预处理优先版本”。
5. 点击“选择媒体文件夹”，选择例如 `D:\BaiduNetdiskDownload\老友记 Friends Season 1` 的总目录。
6. 以后 Reader 切换到另一集时，扩展会自动匹配和载入对应视频。

预处理默认关闭，防止首次配置时立即开始长时间批量转码。勾选后只预处理每一集当前优先的版本，不会同时转换纯英、双语和无字幕三个副本。可以随时点击“停止预处理”，已经完成的结果会保留；稍后点击“重新扫描”即可继续。

Chrome 可能在关闭或重启后收回目录权限。插件会记住目录名称和索引；看到“恢复文件夹权限”提示时，点击“重新扫描”并允许访问即可，不必重新配置路径。

## 已验证

- 真实目录中的 72 个视频文件名全部成功识别剧集编号。
- 真实纯英 MP4：识别为 MPEG-4 Part 2 `mp4v` + AAC，沿用 2.1.1.2 的 H.264 预处理修复。
- 真实无字幕 MKV：快速识别为 H.264 1280×720 + AC3，无需把约 1.5 GB 整文件先写入浏览器内存。
- JavaScript 语法、媒体库匹配测试、MP4 探测测试、MKV 探测测试均通过。
