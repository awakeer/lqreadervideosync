# Reader Sync 2.1.1.8

本版修复播放器恢复可见或重新连接时，同一篇 Reader 文章被反复完整抓取的问题。

## 日志中确认的问题

- S01E19 已经成功抓取 242 段内容后，在不到一分钟内又重复完整抓取两次。
- 每次重复操作都会重新请求 5 页内容，造成额外等待，并可能让界面反复进入准备状态。

## 修复内容

- 后台已有当前文章的新鲜快照时，直接返回缓存，不再通知 Reader 重抓全部页面。
- 浏览器后台刚重启、内存缓存丢失时，Reader 页面会重发最近一次完整快照，而不是立刻重新访问 5 页接口。
- 切换文章、缓存缺失或缓存超过两分钟时，仍会执行新的完整抓取，避免长期使用旧内容。
- 保留 2.1.1.6 引入的断线恢复能力，不影响自动识别 Reader 和自动跟随换集。
