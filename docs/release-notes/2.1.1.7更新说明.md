# Reader Sync 2.1.1.7

本版修复“后台预处理期间切换 Reader 集数后，必须手动停止预处理并重新扫描才能加载新视频”的问题。

## 修复内容

- 批量预处理不再只在开始时排列一次剧集顺序。
- Reader 切换集数后，新集会动态提升到剩余处理队列的首位。
- 如果新集此前已经处理完成，会在当前文件处理结束后直接加载，不再等待整季预处理结束。
- 当前单个文件的预处理会安全完成，避免强制中断造成不完整缓存；之后其余后台任务继续执行。
- 增加切集排队和优先加载日志，方便后续导出日志时判断实际状态。

## 预期表现

预处理正在进行时切换集数，界面会提示新集已进入优先队列。最多等待当前正在处理的一个文件结束，新集便会优先完成处理并自动加载，无需点击“停止预处理”或“重新扫描”。
