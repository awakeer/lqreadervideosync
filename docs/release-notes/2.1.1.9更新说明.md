# Reader Sync 2.1.1.9

本版修复电脑重启后“步骤显示正常、已匹配视频，但播放器仍为未载入并停在 0:00”的问题。

## 修复内容

- 浏览器重启后若本地媒体文件夹权限变为待授权，不再把已保存的匹配索引显示为绿色就绪。
- “重新扫描”按钮会根据状态显示为“重新授权并扫描”，引导恢复文件夹权限。
- 播放按钮在视频尚未恢复时，不再直接对空视频元素调用 `play()`，避免出现 `play() request was interrupted by a call to pause()`。
- 用户点击播放时，会在允许的用户操作中请求文件夹权限，并自动恢复当前集视频。
- 自动加载在权限未恢复时会安全等待，不再反复失败或清空状态。
